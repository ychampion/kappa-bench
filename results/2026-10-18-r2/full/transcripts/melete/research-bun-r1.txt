reply:
The three most recent stable Bun releases, per the [GitHub releases page](https://github.com/oven-sh/bun/releases), are v1.4.3, v1.4.2 and v1.4.1.

- **v1.4.3 (Oct 10, 2026):** It adds `bun check`, a TypeScript type checker built into Bun. The notes call it a port of typescript-go that is about 3–6x faster than `tsc` 7.0.2 and passes TypeScript's conformance tests. They also add `bun run --check`, `bun test --check` and `bun build --check`. [Release notes](https://bun.com/blog/bun-v1.4.3)
- **v1.4.2 (Sep 5, 2026):** This is a bugfix release. One fix is for a v1.4.1 regression where `bun build` renamed a nested `var` to clash with a `let`, which broke builds importing Elysia. [Release notes](https://bun.sh/blog/bun-v1.4.2)
- **v1.4.1 (Sep 4, 2026):** `Bun.serve` now supports HTTP/2 on the same port as HTTP/1.1. The notes report up to 6.8x higher requests per second than `node:http2` in Node.js v26 on a hello-world GET. [Release notes](https://bun.com/blog/bun-v1.4.1)
